# TBlauwe's dotfiles

Personal repository to manage dotfiles across machines using [chezmoi](https://www.chezmoi.io/).

## 🚀 QuickStart 

On Unix / MacOs:

```bash
sh -c "$(curl -fsLS get.chezmoi.io)" -- init --apply TBlauwe 
```


On Windows:

```pwsh
iex "&{$(irm 'https://get.chezmoi.io/ps1')}" --init --apply TBLauwe
```
